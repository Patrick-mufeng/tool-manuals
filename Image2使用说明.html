注册云雾 API

第一步

获取 API Key

觅图需要接入云雾 API 才能生成图片。点击下方按钮注册账号，然后在控制台创建 API Key。

前往云雾 API 注册
1

注册账号

点击上方按钮进入云雾 AI 官网，用手机号或邮箱完成注册

2

充值余额

进入控制台 → 充值中心，建议先充 10 元试用（约可生成 20 张图）

3

创建 API Key

控制台 → API Keys → 创建新 Key，复制以 sk- 开头的密钥

2

工具使用说明

启动

运行程序

解压文件后，双击目录中的 start.bat，看到命令行显示服务启动后，打开浏览器访问：

http://localhost:8000
配置

填入 API Key

首次使用需配置 API 信息：

  • 点击左侧「Key 设置」标签
  • Base URL 保持默认 https://yunwu.ai 即可
  • API Key 填入从云雾控制台复制的密钥
  • 点击「保存设置」，右上角状态变为绿色即连接成功
生成

生成图片

切换到「图片生成」标签，按以下步骤操作：

  • 选择比例（1:1、16:9、9:16 等）和分辨率（1MP ~ 4MP）
  • 选择模型（推荐 gpt-image-2，支持 2K/4K）
  • 输入提示词描述你想要的画面（支持中文）
  • 点击「生成」按钮，等待图片生成
  • 生成完成后可下载、复制链接或重新生成

注意事项

⚠️ 关于费用
本工具本身免费，但生成图片需消耗云雾 API 余额。平均每张约 0.5 元，不同模型价格略有差异，由云雾平台定价决定。
🚫 禁止事项
• 请勿生成违法违规内容（暴力、色情、政治敏感等）
• 请勿将本工具用于侵犯他人版权或肖像权的行为
• API Key 请妥善保管，不要分享给他人
常见问题

遇到问题？

  • 启动失败：确保已运行 install.bat 完成初始化
  • 连接失败：检查 API Key 是否正确，余额是否充足
  • 生成超时：Replicate 模型可能需要 30~60 秒，请耐心等待
  • 图片不显示：检查浏览器是否拦截了本地图片加载
  • 关闭程序：在命令行窗口按 Ctrl + C 即可停止服务
