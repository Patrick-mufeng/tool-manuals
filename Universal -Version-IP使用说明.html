安装指南

五步完成环境搭建，开启 AI 个人 IP 之旅

安装顺序必须严格遵守！Node.js → Git → Reasonix → VS Code → DeepSeek API
01

安装 Node.js

电脑的「翻译官」— 让系统能运行 JavaScript 代码
通俗理解：Node.js 是 Reasonix 的底层依赖，没有它 Reasonix 跑不起来。就像汽车需要发动机，电脑需要这个运行时环境才能执行 AI 相关的代码逻辑。
node-v24.15.0-x64.msi
官网下载
步骤操作
1双击安装文件打开程序
2点击 Next，勾选 I accept the terms
3保持默认路径，一路 Next
4最后一步可勾选 Automatically install tools（可选）
5点击 Install，等待完成
6点击 Finish
验证安装
打开 PowerShell，输入：
node -v
看到 v24.15.0 即成功
02

安装 Git

版本管理工具 — 追踪文件变更历史
通俗理解：就像 Word 的「修订」和「历史版本」功能。Reasonix 用 Git 管理你的项目文件，确保每一步都有记录，随时可以回退到之前的版本。
Git-2.54.0-64-bit.exe
官网下载
步骤操作
1双击安装文件打开程序
2一路点 Next，全部保持默认
3到 Choosing default editor 时，不熟悉 Vim 就选 Use Notepad
4之后全部默认，一路 Next 到底
5点击 Install，等待完成
6点击 Finish
验证安装
打开 PowerShell，输入：
git --version
看到 git version 2.54.0 即成功
03

安装 Reasonix

AI Agent 运行平台 — Skill 的「操作系统」
通俗理解：Reasonix 就像一个「AI 操作系统」。你购买的 Universal-Version-IP 是一个 Skill（技能包），必须在这个平台上才能运行。它是你和 AI 军师对话的入口。
Reasonix_0.47.1_x64-setup.exe
官网下载
步骤操作
1双击安装文件打开程序
2按照引导完成安装（全部默认即可）
3安装完成后打开 Reasonix
验证安装
打开 Reasonix，能看到主界面即为成功
04

安装 VS Code（推荐）

代码编辑器 — 查看和编辑 Skill 生成的文件
通俗理解：VS Code 不是必须的，但强烈推荐安装。装了之后，你可以更直观地查看 AI 生成的选题库、脚本、复盘报告等各种文件，就像用高级记事本打开文档一样简单，体验会好很多。
VSCodeUserSetup-x64-1.120.0.exe
官网下载
步骤操作
1双击安装文件打开程序
2勾选「我同意此协议」，点击下一步
3保持默认路径，点击下一步
4保持默认开始菜单文件夹，点击下一步
5重要！勾选附加任务：将「通过 Code 打开」添加到文件资源管理器目录/文件上下文菜单
6点击下一步 → 安装
7点击完成（可勾选「启动 VS Code」）
验证安装
开始菜单搜索 Visual Studio Code，打开能看到编辑器界面即为成功
05

注册 DeepSeek 并获取 API 密钥

AI 大脑 — 让 Reasonix 拥有智能推理能力
通俗理解：DeepSeek 是国产最强 AI 大模型，Reasonix 需要调用它的 API 才能运行 Skill。API 密钥就像一把「钥匙」，没有它 AI 军师无法为你工作。新用户注册即送免费额度，足够体验完整功能。
前往 DeepSeek 开放平台
步骤操作
1点击上方按钮进入 DeepSeek 开放平台
2点击右上角「登录」，用手机号注册账号
3完成实名认证（需要身份证，约1分钟）
4进入控制台，点击左侧「API Keys」
5点击「创建 API Key」，输入名称（如「Reasonix」）
6立即复制密钥！页面只显示一次，关闭后无法再次查看
7打开 Reasonix → 设置 → 模型配置 → 粘贴 API Key
重要提醒

• API Key 是私密凭证，不要分享给他人，不要截图发到网上
• 现在deepseek 还在打折 趁便宜 立刻拥抱AI
• 如果密钥泄露，立即在 DeepSeek 控制台「删除」并重新创建
• 建议把密钥保存在密码管理器或本地加密文件中

验证配置
打开在 Reasonix 会提示输入key，进入系统说明 API Key 配置成功！

Q

✅ AI 实时监控库存（Buffer），告急时提前提醒备内容。
Q

✅ 无限次！改到你说 OK 为止。
Q

✅ 每个账号建一个独立项目文件夹，分别初始化即可。
Q

✅ Reasonix 运行需要联网（调用 AI 模型），但你的数据全部存在本地。
