完整工作流

从提示词到成品，从生成到伪装，覆盖 AI 图片创作的全链路需求。

01

文生图

支持 OpenAI 与 Replicate 双模式，1MP 至 4MP 分辨率可选，1:1、16:9、9:16 等比例自由切换。中文提示词直接输入，无需翻译。

02

案例库

内置 453 个精选案例，涵盖多种风格与场景。点击即可查看完整提示词，一键复用或修改生成。

03

元数据伪装

批量修改图片 EXIF 信息，自定义相机型号、拍摄参数、地理位置。降低平台对 AI 生成内容的识别概率。

04

批量生成

独立模式下每行输入一个提示词，一次任务生成多张图片。适合需要系列素材的内容创作者。

05

生成历史

所有生成记录自动保存至本地，随时查看、复用、下载。提示词与参数完整留存，便于迭代优化。

06

实时监控

查看每次请求的完整 JSON 数据，请求体、响应体、耗时一目了然。调试与排查问题更高效。

使用流程

三步开始创作

无需配置环境，无需理解代码。从解压到出图，五分钟上手。

1

注册云雾 API

首先需要在云雾 AI 平台注册账号并获取 API Key。这是生成图片的必要前提。

点击注册云雾 API
2

启动并配置

解压文件，双击 start.bat 启动服务。浏览器访问 localhost:8000，在「Key 设置」中填入 API Key。

3

输入生成

选择比例、分辨率、模型，输入提示词，点击生成。图片自动下载至本地文件夹。
